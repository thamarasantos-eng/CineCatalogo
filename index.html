Sobre o projeto

O CineCatálogo é um projeto acadêmico da disciplina de Desenvolvimento Web, construído com HTML semântico, Bootstrap 5 e JavaScript puro. A listagem de filmes e os detalhes de cada título são carregados por requisições AJAX (Fetch API) a partir de arquivos JSON, sem necessidade de recarregar a página.

Consulte o arquivo README.md do repositório para instruções de execução, fontes de dados e um roteiro de testes.
